개인정보처리방침

시행일: 2026년 10월 21일

30초픽 자동 업로드는 운영자 본인의 YouTube 채널 운영을 위한 개인용 Windows 프로그램입니다.

접근 정보와 목적

YouTube 채널 식별자·채널 정보, 업로드한 영상의 식별자·공개 상태·예약 시각에 접근합니다. 운영자가 선택한 영상 파일·제목·설명을 YouTube API로 전송합니다. 본인 채널 확인, 승인된 영상 업로드, 예약 공개 및 중복 방지에만 사용합니다.

인증·보관·공유

OAuth 인증 정보와 작업 기록은 운영자 PC에서 관리합니다. 인증 정보는 Google 인증 서버와의 토큰 갱신에 사용하며 비밀번호는 수집하지 않습니다. Google/YouTube API 외의 제3자에게 Google 사용자 데이터를 전달하지 않습니다. 데이터를 판매하거나 광고·AI 모델 학습에 사용하지 않습니다.

접근 철회와 삭제

사용 중지 후 Google 계정의 보안 설정에서 앱 접근을 철회하고 로컬 인증 정보·기록을 삭제할 수 있습니다. 이미 업로드한 영상은 YouTube Studio에서 별도로 삭제해야 합니다. 문의 및 정보 삭제 요청: chopigbb@gmail.com

Google API 사용자 데이터

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요건을 준수합니다.
